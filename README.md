MediZen – Your Healthcare Companion

About:
MediZen is an accessibility-first healthcare companion designed to help adults aged 60 and above manage everyday healthcare needs through a simple interface.

Problem Statement:
Older adults may struggle with medicine schedules, appointments, complex digital interfaces, and accessing help during emergencies.

Key Features:
- Medicine management and appointment tracking
- Emergency SOS and caregiver contacts
- Nearby hospital discovery and health tips
- English and Tamil language support
- Adjustable text size and read-aloud assistance
- Simple, accessible interface

Technologies Used:
HTML, CSS, JavaScript, Web Speech API, Local Storage, Capacitor, Visual Studio Code, Git, GitHub, and Android Studio.

How to Run MediZen:
1. Open the "MediZen GitHub repository" (https://github.com/gayathris12122008/MediZen).
2. Click Code → Download ZIP.
3. Extract the downloaded ZIP file.
4. Open the extracted project folder in Visual Studio Code.
5. Locate "index.html".
6. Right-click "index.html" and select Open with Live Server if the VS Code Live Server extension is installed.
7. MediZen will open in your default browser. 
(Working on the mobile app interface, will be updated soon!) 
Current Status:
MediZen is a web-based prototype being developed for Android. Some features may require further testing and configuration.

Limitations:
Emergency functions depend on device permissions, network availability, and correct contact details. Health tips do not replace professional medical advice.
